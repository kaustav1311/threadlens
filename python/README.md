# threadlens (Python)

Local, offline analysis of WhatsApp chat exports: questions vs assertions, heat,
evidence, rhythm and argument rigor. Mirrors the scoring used by the web app.

```bash
pip install -e ".[dev]"
threadlens analyse chat.txt --lens rigor
threadlens serve
```

Full documentation: see the [project README](https://github.com/kaustav1311/threadlens#readme).
